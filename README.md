# SECO LOG

**일상의 생산적 관리부터 특별한 여행 기록까지, 나만을 위한 스마트 라이프 플래너 & 오거나이저**

**배포 URL**: [https://my-planner-lovat.vercel.app/](https://my-planner-lovat.vercel.app/)

---

## 프로젝트 소개 (About Project)

**SECO LOG**는 일상의 **To Do LIST, 주간/월간 스케줄, 자산 관리(월간 가계부)**를 효율적으로 관리함과 동시에, **여행 프로젝트(일정, D-Day, 여행 가계부, 예약 티켓 바우처, 포토 다이어리, 추억 갤러리)**를 하나의 통합된 공간에서 직관적으로 사용할 수 있도록 설계된 개인 맞춤형 대시보드 웹 서비스입니다.

PC 환경의 넓은 스플릿 레이아웃 지원은 물론, 모바일 터치 환경에 최적화된 **가로 스와이프(Snap Slider)** 및 **모바일 전용 탭(Tab UI)**을 적용하여 언제 어디서나 쾌적하게 사용할 수 있습니다.

---

## 개발 환경 및 기술 스택 (Tech Stack)

- **프레임워크 (Framework)**: Next.js 14 (App Router)
- **라이브러리 (Library)**: React 18
- **언어 (Language)**: TypeScript
- **스타일링 (Styling)**: Tailwind CSS v4, Pretendard 웹폰트, Custom Utility Class (`btn-day-active`, `btn-day-inactive`)
- **백엔드 & 데이터베이스 (Backend & DB)**: Supabase (PostgreSQL, Supabase Storage)
- **배포 도구 (Deployment)**: Vercel
- **데이터 시각화 (Visualization)**: Recharts
- **아이콘 (Icons)**: Lucide React
- **버전 관리 (VCS)**: Git / GitHub

## 핵심 UX & 디자이너 포인트 (UX Highlights)

- - 프로젝트 동적 테마 컬러 시스템\*\*: 여행 등록 시 선택한 테마 색상(`selectedTrip.color`)이 상세 일정, 포토 일기, 여행 가계부의 Day 탭까지 실시간 동기화되어 통합된 브랜드 감성을 제공합니다.
- - 스와이프 인터랙션 (`snap-x snap-always`)\*\*: 모바일 화면에서 일자별(Day) 일정, 포토 다이어리, 지출 내역을 손가락으로 자연스럽게 스와이프하며 조회할 수 있으며, 하단 슬라이드와 상단 Day 탭의 스크롤 위치가 100% 연동됩니다.
- - 모바일 전용 탭 UI\*\*: 모바일 대시보드의 길어지는 세로 스크롤을 방지하기 위해 `[오늘의 투두]`, `[금주 일정]`, `[내 여행]`, `[경비/서류]` 탭으로 분리하여 손쉬운 정보 탐색이 가능합니다.
- - 지난 미완료 Task(Overdue) 추적\*\*: 오늘 날짜 이전에 처리하지 못한 지연된 할 일을 상단 경고 바에 모아주고 `[오늘로 미루기]` 기능을 통해 일상의 누락을 방지합니다.

## 핵심 메뉴 및 주요 기능 (Features)

### 1. 메인 대시보드 (`/`)

- **대시보드 퀵 서머리**: 오늘 챙겨야 할 미완료 Task(지연 항목 포함) 및 금주 스케줄 요약 노출
- **오늘의 To Do & 금주 스케줄**: 메인 화면 접속 시 일상 속 핵심 Task 실시간 체크 및 주간 달성률 그래프 시각화
- **여행 프로젝트 카드**: 다가오는 여행의 **D-Day 카운트다운**, 여행지, 기간 정보 및 포토 일기 바로가기
- **서브 위젯**: 여행 누적 지출 금액 요약 및 보관된 서류 **`미리보기`** 모달 팝업 지원 (바우처/QR 즉시 확인)

---

### 2. 개인 관리 (Personal Management)

#### **캘린더 (`/calendar`)**

- 월간 일정 등록 및 일정별 커스텀 컬러 지정
- 개인, 업무, 여행 일정을 한눈에 파악하는 전체 스케줄 타임라인

#### **To Do LIST (`/todo`)**

- 주간 요일별 캘린더 탭 필터링 및 카테고리(`개인`, `업무`) 구분 관리
- **지난 미완료 할 일(Overdue)** 별도 상단 알림 바 노출 및 **`오늘로 미루기`** 1-Click 연동
- 실시간 완료 체크 및 주간 달성률 프로그레스 바 시각화

#### **월간 가계부 (`/account-book`)**

- 일상 생활비 및 용돈 관리를 위한 수입(+)/지출(-) 내역 기록
- **`이번 달 남은 돈`** 자동 집계 (총 수입 - 총 지출)
- Recharts 기반 지출 카테고리별 비중 도넛 차트 제공 및 내역 수정/삭제 지원

---

### 3. 여행 프로젝트 (Travel Projects)

#### **여행 일정 (`/trips`)**

- 프로젝트별 메인 여행 등록 (여행지, 출발/도착일, 테마 컬러 설정)
- Day별 동적 스와이프 타임라인을 통한 일정 추가, 장소(구글 맵 연동), 티켓 서류 연결 지원
- 준비물 및 쇼핑 리스트 체크리스트 관리

#### **여행 경비 관리 (`/expenses`)**

- 실시간 환율 API 연동을 통한 현지 통화 ↔ 원화(KRW) 자동 환산
- 결제 수단별(현금/트래블카드 vs 신용카드) 지출 분리 관리 및 남은 환전 잔액 게이지 바 제공
- **Day별 가로 스와이프 필터** 및 선택 일자 지출 합계 실시간 계산

#### **예약 & 티켓 보관소 (`/attachments`)**

- 호텔 바우처, E-티켓, QR코드 등 중요 예약 서류 보관 (Supabase Storage)
- 대시보드 및 상세 페이지에서 **`미리보기`** 클릭 시 PDF/이미지 팝업 모달 노출

#### **여행 기록 다이어리 (`/diaries`)**

- Day N별 포토 에세이 및 일기 작성 (스와이프 슬라이더 뷰 지원)
- 다중 이미지 첨부, 접기/펼치기 및 별점(Rating) 평가 기능

#### **추억 갤러리 (`/gallery`)**

- 등록된 모든 여행 사진을 인스타그램 피드 형태의 바둑판 그리드로 모아보기
- 여행 프로젝트별 사진 필터링 및 대형 라이트박스 팝업, 관련 일기 바로가기 지원

## 프로젝트 구조 (Directory Structure)

```text
my-planner/
├── app/
│   ├── page.tsx            # 메인 HOME 대시보드 (모바일 탭 & 지연 Task 연동)
│   ├── calendar/           # 캘린더 페이지 (월간 스케줄)
│   ├── todo/               # To Do LIST 페이지 (주간 캘린더 & 지난 미완료 추적)
│   ├── account-book/       # 월간 가계부 & Recharts 자산 차트 페이지
│   ├── trips/              # 여행 프로젝트 일정 페이지 (Day 스와이프 타임라인)
│   ├── expenses/           # 여행 경비 관리 페이지 (실시간 환율 & Day 스와이프)
│   ├── attachments/        # 예약 서류 및 티켓 보관소 (팝업 모달)
│   ├── diaries/            # 여행 기록 포토 다이어리 (스와이프 뷰er)
│   └── gallery/            # 추억 갤러리 피드 페이지 (라이트박스 모달)
├── components/
│   └── Sidebar.tsx         # 반응형 좌측 고정 사이드바 (PC/모바일)
├── lib/
│   └── supabase.ts         # Supabase Client 설정
└── public/                 # 정적 리소스
```
